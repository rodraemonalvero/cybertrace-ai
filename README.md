# CyberTrace AI
## An AI-Powered Internship and Career Readiness Assistant

CyberTrace AI is an AI-powered website designed to help college students evaluate how their academic skills, projects, and experience match internship and entry-level job requirements.

## Project Information

- Course: CSE/MB 598 – Internship for Capstone
- Institution: California Science and Technology University (CSTU)
- Developer: Rod Raemon Alvero
- Project Type: Individual Capstone Project
- Project Direction: Discover Opportunities
- Target Completion: December 22, 2026
- Status: Approved – Development in Progress

## Project Objectives

1. Allow students to enter their skills, education, and project experience.
2. Allow users to paste internship or job descriptions.
3. Use AI to identify matching qualifications and possible skill gaps.
4. Generate career-readiness recommendations.
5. Generate professional networking messages for users to review and edit.

## Planned Technologies

- Frontend: Next.js
- Backend: Python FastAPI
- AI: Free or locally hosted language model (to be selected)
- Development Environment: Visual Studio Code on Windows
- Version Control: Git and GitHub

## Planned Workflow

1. Student enters their skills and academic experience.
2. Student pastes an internship or job description.
3. CyberTrace AI analyzes both inputs.
4. The application generates a career-readiness report.
5. Student reviews the results and edits the suggested networking message.

## Project Scope

The initial version will focus on one complete career-readiness analysis workflow.

It will not require live job scraping, LinkedIn integration, or a standalone chat application.

## Privacy and Safety

- Users control the information they submit.
- The application will not automatically send networking messages.
- The AI should not invent qualifications or work experience.
- Personal information will not be permanently stored in the initial version.
- Any use of external AI services will be disclosed.

## Planned Deliverables
